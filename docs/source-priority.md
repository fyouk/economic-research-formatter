# Source priority and conflict policy

## 1. 不假设“哪个文件更新”

当前资料没有可靠的发布日期/版本号。因此跨文件冲突不能通过文件名、排版风格或主观判断自动决定新旧。

## 2. 同一整理文件内部

对于 `ER-MS-IMG-NOTES`：

1. 原图红色批注（`red_annotation`）
2. 整理稿中对红色批注的直接操作性转述（`operational_summary`）
3. 从示例观察到的版式（`example`）

其中 1 的证据等级高于 2 和 3。

这并不代表它天然高于另一份独立规范；跨来源仍需看是否冲突。

## 3. 独立来源之间

- 如果互补：两条都保留。
- 如果一条更具体、另一条不否定：可以标记为 `unresolved_overlap`，在人工裁决前避免高风险自动修改。
- 如果直接矛盾：必须加入 `rules/conflicts.yaml`。
- 如果只是示例与明确要求不同：保留差异；明确要求可以作为有效规则，但需要在 conflict 记录中解释原因。

## 4. 禁止行为

不得因为“通常经济学期刊都这样”而补规则。
不得用通用 APA / Chicago / GB/T 规则替换现有来源。
不得自动纠正来源中保留的特殊拼写或大小写示例。
